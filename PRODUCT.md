# Product
Daily Work is a personal daily work journal with a monthly calendar, titles, notes, categories, optional hours, search, editing, deletion and JSON export. Localhost defaults to Python standard-library server and SQLite storage, without accounts. Hosted sites use Supabase email/password authentication and PostgreSQL with owner-only Row Level Security. Vercel serves the static public directory. Local entries remain local; migration is not automatic. Test hosted behavior locally with ?cloud=1.
