# Daily Work
A personal local website for daily work notes. Requires Python 3 (no packages).

Double-click start.bat, or run `python server.py`, then visit http://127.0.0.1:8080.
Keep the terminal open while using the website. Close it to stop the server.

Entries are stored in data/worklog.sqlite3. Copy that file while the app is stopped for a complete database backup. Export JSON from the app for a readable copy of all entries. The site uses no external services or fonts and works offline. It listens only on this computer.
